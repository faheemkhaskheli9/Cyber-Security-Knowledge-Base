# Security Policy

## Supported versions
Only the latest release receives security fixes.

## Reporting a vulnerability
Please **do not** open a public issue. Use GitHub's "Report a vulnerability" (Security tab → Advisories) or email security@example.com.
Include: description, impact, reproduction steps, affected version.
We aim to acknowledge within 3 business days and provide a fix/timeline within 30 days. We support coordinated disclosure.
