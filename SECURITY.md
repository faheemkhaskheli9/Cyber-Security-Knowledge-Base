# Security Policy

## Supported versions
This repository has no releases; only the current `main` branch (KB content, `scripts/`, `templates/` and `webapp/`) receives fixes.

## Reporting a vulnerability
Please **do not** open a public issue. Use GitHub's private vulnerability reporting: Security tab → Advisories → "Report a vulnerability".
Include: description, impact, reproduction steps and the affected file or commit.
We aim to acknowledge within 3 business days and provide a fix/timeline within 30 days. We support coordinated disclosure.

Wrong or outdated security guidance in `kb/` is not a vulnerability; open a normal issue for it.
