# Attack Frameworks & Models

- **Lockheed Martin Cyber Kill Chain**: Recon → Weaponize → Deliver → Exploit → Install → C2 → Actions on objectives.
- **MITRE ATT&CK**: Tactics (Initial Access, Execution, Persistence, Privilege Escalation, Defense Evasion, Credential Access, Discovery, Lateral Movement, Collection, C2, Exfiltration, Impact) with techniques/sub-techniques. Use to map detections and coverage gaps (ATT&CK Navigator).
- **MITRE D3FEND**: defensive countermeasure knowledge graph.
- **Diamond Model**: adversary, capability, infrastructure, victim.
- **Unified Kill Chain**, **Pyramid of Pain** (hashes → IPs → domains → artifacts → tools → TTPs; hunt higher up).
- **CVE / CWE / CVSS / EPSS / KEV**: identifier, weakness class, severity, exploit probability, known-exploited list (prioritize KEV).
- **NIST CSF 2.0**: Govern, Identify, Protect, Detect, Respond, Recover.
