# Glossary
**APT** advanced persistent threat · **BEC** business email compromise · **C2** command & control · **CSPM** cloud security posture mgmt · **CVE** common vulnerabilities & exposures · **CVSS** severity score · **DAST/SAST/IAST/SCA** testing types · **DLP** data loss prevention · **EDR/XDR** endpoint/extended detection & response · **EPSS** exploit prediction · **IAM** identity & access mgmt · **IDS/IPS** intrusion detection/prevention · **IOC/IOA** indicator of compromise/attack · **KEV** known exploited vulns · **LOLBin** living-off-the-land binary · **MFA** multi-factor auth · **PAM** privileged access mgmt · **PoC** proof of concept · **RCE** remote code execution · **SBOM** software bill of materials · **SIEM/SOAR** log analytics/orchestration · **SSRF** server-side request forgery · **TTP** tactics, techniques, procedures · **WAF** web app firewall · **XSS** cross-site scripting · **Zero-day** unpatched, unknown-to-vendor flaw · **Zero trust** verify every request.
